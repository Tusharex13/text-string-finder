# Text String Finder

A Python program to search and highlight strings inside text files.

## Features
- Case-sensitive search
- Shows total occurrences
- Displays line numbers
- Shows context (50 lines before and after)
- Terminal highlighting

## How to Run

```bash
python find_in_file.py
```

Then enter:
- File name
- String to search

## Requirements
- Python 3.x
